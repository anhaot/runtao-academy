# 用户手册

## 1. 系统用途

技术成长站用于管理技术题库、治理知识内容、调用 AI 协助完善题目，并通过背题、答题、收藏和学习进度完成持续复习。

主要角色：

- 学习用户：查看授权题库、背题、答题、收藏和使用获准的 AI 功能。
- 题库维护者：新增和编辑题目，维护分类、标签、重复题和导入导出。
- 管理员：管理用户、权限、AI 凭据、模型、备份和数据库。

页面包括：首页、题库、记题、背题、答题、收藏和设置。页面是否显示取决于当前用户权限。

## 2. 登录与账户

登录需要用户名、密码和图形验证码。默认管理员账号和密码均为 `admin`，首次登录后必须设置至少 9 位且同时包含字母和数字的新密码。

右上角个人资料可以修改用户名、邮箱和密码。登录状态使用浏览器 Cookie；如果刷新后退出，请检查 Cookie、HTTPS 和反向代理域名配置。

## 3. 首页

首页展示当前题库和学习概况，并提供主要模块入口。数据范围会遵循用户类型和分类授权：独立题库用户查看自己的数据，集成题库用户查看被授权的共享题库。

## 4. 题库管理

题库页是内容维护中心，支持：

- 新增、编辑、查看和删除题目
- 按关键词、分类、标签和难度筛选
- Markdown 答案与解析
- 批量删除、批量标签和 AI 批量标签
- CSV、JSON、Markdown 和文本导入
- 题库导出
- 相似题检查与重复题合并

### 新增和编辑

题干为必填项；标题、答案、解析、分类、标签和难度可以按需填写。答案为空时可以先调用 AI 生成草稿，但保存前应人工确认。

编辑权限分为内容和元信息两类：

- 内容：题干、答案、解析。
- 元信息：分类、标签、难度等。

如果按钮不可见或保存返回无权限，请联系管理员检查对应权限和分类范围。

### 标签与重复题治理

设置中的分类与标签页支持查看标签健康状况、重命名、删除和规范化。重复题功能可以列出相似题并选择保留内容，合并前建议先导出备份。

### 导入与导出

导入前先确认文件格式和字段映射。大量导入完成后建议检查：

1. 题目总数。
2. 分类和标签。
3. 空答案或格式异常题目。
4. 重复题结果。

## 5. AI 内容协作

### 批量生题

进入 `题库 → AI批量生题`，填写主题和数量，选择内容深度与模型。生成结果会先展示预览，确认后再导入题库。

### 答案草稿

单题的 `AI答案` 只生成答案、解析和标签建议，不修改题干。可以编辑草稿后保存。

### 题目润色

单题的 `AI润色` 可以优化整道题。轻润色偏表达修正，深润色允许更完整的内容重组。保存前会显示草稿。

### AI 助手

学习页面中的助手能够结合当前题目进行分析、扩展、知识推荐、相似题生成和继续对话。模型选择器会列出设置中的全部已配置模型。

AI 输出不是自动认可的标准答案。用于正式题库或培训内容前应人工复核。

## 6. 背题和答题

### 背题

背题模式适合逐题阅读、回忆和查看答案。可以：

- 上一题、下一题或随机切题
- 显示或隐藏答案
- 记录掌握程度和复习进度
- 收藏重点题
- 调用 AI 助手补充解释

### 答题

答题模式适合先组织答案，再与标准答案和解析对照。系统会保存浏览和学习进度，便于下次继续。

筛选条件会影响学习题集；发现题目数量不符合预期时，先检查分类、标签和难度筛选。

## 7. 收藏

收藏页集中显示重点题。可以从题库、背题或答题页面切换收藏状态。收藏不会复制题目，只记录当前用户与原题目的关联。

## 8. 批量内容草稿

`记题` 页面是一个辅助录入入口，适合一次记录多道尚未整理的题目：

1. 一行一道题；较长内容可用空行分隔。
2. 保存到当前浏览器草稿箱。
3. 选择草稿调用 AI 补充答案、解析和标签。
4. 人工检查并编辑。
5. 选择确认无误的内容导入正式题库。

草稿与正式题库隔离。浏览器本地草稿不会自动上传；共享设备使用后应清理草稿和站点数据。

## 9. 分类、标签和权限

设置页根据权限显示以下标签：

- 系统：账户、用户、权限、备份等。
- 分类与标签：分类结构和标签治理。
- AI：API 凭据、模型配置和默认模型。
- 数据库：数据库连接、迁移和校验。

管理员可以为用户设置独立题库或集成题库，并分别授予查看、新增、编辑、删除、导入、AI、标签、备份和系统管理权限。详细规则见 [permissions.md](permissions.md)。

## 10. AI 凭据和模型

### 添加凭据

进入 `设置 → AI设置 → API 凭据`：

1. 填写凭据名称。
2. 填写 OpenAI 兼容 Base URL。
3. 填写 API Key。
4. 保存。

Key 不会显示在模型配置中。一个凭据可以供多个模型使用，编辑凭据后关联模型会一起更新。

### 添加模型

在 `API 配置` 点击“添加配置”，选择凭据、读取模型列表并选择模型。保存后可以设置为默认模型。

### 检查模型

点击“检查模型可用性”后，系统最多同时检查 4 个模型。哪个模型先返回，哪个先显示结果；其他模型继续等待。全部完成后弹窗汇总：

- 可用
- 不可用
- 无法确认
- 其中超时数量

“能读取模型列表”不等于“有权调用模型”。系统会额外执行一次最小推理请求。

## 11. 备份、恢复和数据库

管理员可以导出完整备份。备份包含用户、分类、题目、学习数据、AI 配置、API 凭据和系统设置；AI Key 保持加密状态。

恢复或切换数据库前：

1. 导出当前备份。
2. 确认 `AI_CONFIG_ENCRYPTION_KEY` 未改变。
3. 在低峰期执行。
4. 完成后检查登录、题目数量、分类、权限和 AI 配置。

数据库页支持 SQLite 与 MariaDB / MySQL 配置的连接测试、初始化、迁移、校验和重启后切换。

## 12. 常见问题

### 页面更新后仍是旧界面

Windows/Linux 使用 `Ctrl + F5`，macOS 使用 `Cmd + Shift + R`。PWA 环境还可以关闭所有页面后重新打开。

### AI 返回 401

Key 无效、类型不正确或不适用于当前 Base URL。到 API 凭据中更新 Key。

### 模型列表存在但检查失败

提供商可能允许查看目录但未授予推理权限。查看模型行下方的错误详情，尝试其他模型、网络出口或账号。

### 模型检查等待较久

较快模型会先显示结果。慢模型最长等待当前服务设置的超时时间，最终汇总弹窗会单独统计超时或无法确认项。

### 无法删除 API 凭据

仍有模型引用该凭据。先删除关联模型，或把模型切换到其他凭据。

### 题目或按钮看不到

检查当前用户的题库类型、分类授权和功能权限。管理员权限不应通过前端显示判断，最终以后端权限校验为准。
