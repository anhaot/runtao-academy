# AI 功能说明

## 1. 总览

当前系统内主要有四类 AI 能力：

- AI 批量生题
- AI 题目润色
- AI 答案草稿
- AI 助手

它们的定位不同，不建议混用。

---

## 2. AI 批量生题

入口：题库页 `AI批量生题`

支持三种模式：

- `速记版`
- `练习版`
- `教学版`

适合场景：

- 围绕一个主题快速扩充题库
- 初始导入后补题
- 新知识点建库

特点：

- 返回题目数组
- 支持直接导入题库
- 当前后端已经兼容更多 JSON 返回格式，稳定性更高

---

## 3. AI 题目润色

入口：题库页每题的 `AI润色`

支持两档：

- `轻润色`
- `深润色`

### 轻润色

- 默认档位
- 更偏表达优化
- 尽量少改原题结构
- 通常更快

### 深润色

- 更偏整体优化
- 可以加强答案和解析
- 适合原题质量较差时使用
- 通常更慢

润色流程：

1. 生成草稿
2. 对比原题与润色稿
3. 手工调整内容
4. 选择标签
5. 保存写回

---

## 4. AI 答案草稿

入口：题库页每题的 `AI答案`

定位：

- 只生成答案、解析和标签建议
- 不改题干、标题、难度

支持模式：

- `速记版`
- `练习版`
- `教学版`

### 速记版

- 更短
- 但要求完整可理解
- 适合背诵和快速作答

### 练习版

- 更适合刷题对照
- 保持完整且不过度展开

### 教学版

- 更完整
- 更适合讲解和带理解

---

## 5. AI 助手

入口：题目详情 / 辅助区域

支持：

- 题目分析
- 答案扩展
- 知识推荐
- 相似题生成
- 深度对话

适合：

- 学习理解
- 补充背景
- 口语化讲解

---

## 6. 标签相关 AI

### 单题标签建议

- `AI答案`
- `AI润色`

### 批量标签建议

- 选中多道题
- 使用 `AI批量标签`

适合：

- 老题库补标签
- 标签治理
- 批量整理

---

## 7. 模型配置说明

系统支持两类 AI 配置：

- 内置供应商配置
- 自定义地址配置

当前安全策略：

- 普通用户可以使用已有的安全自定义模型
- 普通用户不能新增或修改自定义 `baseUrl`
- 管理员可以管理自定义地址

### 7.1 模型状态检查

入口：`设置 -> AI设置 -> API配置`

管理员可以对已有模型配置执行检查：

- `检查失效模型`：批量读取各配置 API 地址的 `/models` 列表，并标记模型是否仍可用
- 单条配置的检查按钮：只检查当前配置
- `清除失效模型`：一键删除已经标记为 `已失效` 的模型配置

检查结果会显示在配置列表中：

- `可用`：当前模型仍在 API 地址返回的模型列表中
- `已失效`：当前模型不在模型列表中
- `无法确认`：API 地址、网络、密钥或模型列表返回格式异常，系统不会自动删除

### 7.2 自定义 API 地址模板

自定义提供商支持 OpenAI 兼容 API 地址，例如 NVIDIA NIM。

新增或编辑配置时：

1. 选择 `自定义提供商`
2. 从 `选择已有 API 地址模板` 选择已保存过的地址，或新增一个 API 地址模板
3. 填写或调整 `API地址模板名称`
4. 填写 `API地址 (Base URL)`
5. 读取模型列表并选择模型
6. 保存配置

说明：

- API 地址模板按 `baseUrl` 归类，不按模型名归类
- `https://integrate.api.nvidia.com/v1` 会识别为 `NVIDIA`
- 模板名称可以手动调整
- 模型配置的 `显示名称` 与 API 地址模板名称是两件事
- `显示名称` 留空时，会使用所选模型名称作为显示名

### 7.3 密钥复用

如果选择的是已经保存过的自定义 API 地址模板：

- API 密钥可以留空
- 读取模型列表时会复用已有配置的密钥
- 保存新模型配置时也会复用已有配置的密钥

只有第一次新增一个全新的自定义 API 地址时，才需要填写 API 密钥。

---

## 8. 体验与性能说明

AI 功能耗时不是完全一致的。

一般来说：

- `AI答案` 较快
- `AI批量生题` 中等
- `AI润色` 最慢，尤其是 `深润色`

当前前端已经补了长耗时提示，避免误判成卡死。

---

## 9. 使用建议

推荐顺序：

1. 批量生题先铺题量
2. AI答案补答案与标签
3. AI润色处理重点题
4. 批量标签做后期治理

如果只是“答案太弱”，优先用 `AI答案`。  
如果是“整道题质量不高”，再用 `AI润色`。
